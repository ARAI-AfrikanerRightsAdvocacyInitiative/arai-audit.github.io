Forensic Audit Methodology / Forensiese Oudit Metodologie

1. E-pos Header Oorsprong / Email Header Origin

Elke e-pos het 'n "vingerafdruk" (metadata). Dit bewys dat weierings outomaties en in groepe (batch) gestuur is.

  • Gmail: Klik op die drie kolletjies langs 'Reply' -> "Show Original".
  • Soek vir: "Message-ID" en "AuthSource".
  • Doel: Deur die tydstempel en AuthSource te vergelyk, bewys ons of aansoekers op dieselfde tydstip deur dieselfde stelsel verwerk is.

2. ARAI Bel-Protokol / ARAI Forensic Call Protocol

Beste Tyd: 14:30 – 16:00 (SAST) | 08:30 – 10:00 (EST)

Die Vrae (Melk die Stelsel):

  1. "Can I have your Agent ID and a Call Reference Number for my records?"
  2. "Can you confirm the last date that an action was recorded on my receipt number [NOMMER]?"
  3. "Is my file currently with a human officer, or is it with a processing unit?"
  4. "Could you please confirm the current status of my file in the system metadata?"
  5. "Is there any action required from my side, or is the file strictly in internal processing?"

As die agent verwys na 'n portaal: "I do not have reliable internet access to navigate that portal. I am relying on this call to verify my status for my personal records."

3. Tier 2 Eskalering / Tier 2 Escalation

Indien die agent nie kan help nie, vra vir eskalasie:

"I have a procedural synchronization error on my file that requires an officer with advanced access to review. Please escalate to a Tier 2 officer."

Vra vir Tier 2: "Can you confirm the Officer ID or Unit Code responsible for this file, the last date of a human case-note, and the current 'Reason Code' entered in the system?"

4. Belangrike Advies / Important Advisory

Moenie: Praat oor weieringsbriewe, "Rep 16", of onbevoegdheidskennisgewings nie. Bly streng by die "prosedurele status".

Beskerm jou FOIA: Moenie jou FOIA-lêer met derde partye deel nie. Dit is jou privaat sleutel. Dien dit slegs individueel by die Ombudsman in.
